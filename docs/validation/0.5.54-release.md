integration worktree; no production deployments or mutations.

- Baseline `809b87c4`: `go test -p 1 ./...` passed; UI `npm ci --ignore-scripts

- Integrated backend: `GOMAXPROCS=2 GOMEMLIMIT=1024MiB go test -p 1 ./...`
  and `go vet -p 1 ./...` passed, including privileged helpers and server tests.
- Integrated UI: `npm run build` passed before and after the translation fix.
  Existing large-chunk advisory remains; it is not a new regression.

  unchanged satoshi values, Wallet/dashboard, shared quotes, persistence,
  unavailable/stale quotes, PT/EN and mobile selector behavior.

  interactions using synthetic local APIs, EN/PT at 1280/768/390px, no horizontal
  overflow, historical translation, inline error, dismiss menu containment,
  expired-to-done, set-fee navigation, and opt-in quote above/below the cap.

These browser checks do not exercise a live PostgreSQL decision round-trip,
live Loop service or mainnet financial operations. The release does not claim
